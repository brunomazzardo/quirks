## What this changes

Today Quirks demands each vendor CLI emit a rigidly-shaped JSON envelope. That demand is
where the bugs live. Instead: a **launcher** that only knows how to *start* codex, cursor,
and claude correctly, and a **managing agent** — one sonnet subprocess per job, spawned by
Quirks — that runs the CLI, reads whatever it actually produced (final message, transcript,
files, git state), and returns the structured `RunnerJobResult`.

The decisive measurement, which you should not re-derive: `--output-schema` does not merely
constrain codex's final message, it **eliminates its reasoning**. Same brief, same model —
0 prose messages with the schema, 8 substantive messages including two real Criticals
without it. So the launcher **drops** `--output-schema`; it is not made optional.

## My three decisions (already made, do not re-litigate)

1. **Sonnet interprets**, one call per job. Haiku was rejected: the load-bearing behaviour is
   *refusing to guess* a verdict, and that is where a small model drifts invisibly.
2. **Retry the interpretation once, then fail with the transcript kept.** There is
   deliberately **no fallback to the schema path** — with `--output-schema` dropped there is
   no envelope left to parse. Re-running the whole job under the schema was rejected: pays
   twice and suppresses the reasoning again.
3. **Delete the strict envelope paths** once the agent path carries real traffic — the
   brief-stated contracts, the strict parsers, and the fake-runner mimicry they forced. A
   flagged baseline was rejected: two live result paths mean two sets of fakes to keep
   faithful, which is exactly what produced the test/production divergence.

## Honesty constraints — the part most worth getting right

An interpreting agent is a place where a result could be invented. Non-negotiable:

- The managing agent **reports what the runner said; it never judges the work.** It has no
  authority to accept, and its brief must say so.
- **A verdict must quote its supporting evidence** from the transcript, stored with the
  result. A verdict unsupported by the transcript is a runner failure, not an accept.
- **Absence fails closed.** Cannot determine a verdict → `indeterminate`, which withholds
  acceptance. Never "accept".
- **The raw transcript is always retained** so any interpretation stays auditable.
- The agent runs **read-only** for reviewer jobs; it cannot mutate task, campaign, or repo state.
