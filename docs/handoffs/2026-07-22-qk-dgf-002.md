# QK-DGF-002 dogfood release repair handoff

## Direction

Quirks is a project-agnostic local control plane for agents and humans to plan, dispatch, observe, review, and audit work across repositories. It is a standalone plugin/CLI/UI, not an infra-console-specific module. The intended shape is:

- canonical task-source abstraction, with repository JSON first and GitHub Issues, Linear, Jira, ClickUp, and other providers added through adapters;
- provider status remains authoritative when an external source is selected, while Quirks normally performs semantic updates and durable sync;
- portable agent dispatch across Claude, Codex, and Cursor, with explicit model/effort routing, independent reviewers, Git worktrees, budgets, and approval envelopes;
- a loopback-only React/TanStack UI for preflight approval, dependency/wave maps, live plan progress, existing tasks, past campaigns, source refs, commits, PRs, verification, and participant identity;
- compact references to specs/plans/commits/PRs rather than duplicated source content;
- GitHub remains the source/build system. Quirks coordinates execution and records evidence; it does not replace Git or pretend a local summary is authoritative proof.

The near-term goal is to dogfood Quirks to finish Quirks. The old overnight run exposed that the control plane and UI were largely implemented, but the claimed real host/runner, marketplace, and bounded-campaign release gates were not real. `QK-DGF-002` repairs that boundary before any release claim.
